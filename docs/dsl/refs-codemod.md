# Срез 2: кодмод на форме со ссылками против формы на строках

Статус: проба. Стенд: ts-morph 28.0.0, TypeScript 6.0.2, prettier 3.9.6, Node 20.19.0.
Фикстуры в `scratchpad/probe-dsl` — граф `load_hotels → score_hotels(map) → top3(code) →
pick(switch) → render` с комментарием, пустой строкой внутри тела `code` и `switch` с двумя
ветками: `flowA.ts` (строки) и `flowB.ts` (ссылки), обе проходят `tsc --strict`. Хвост `flowB.ts`:

```ts
export default defineFlow({ flow: "hotel_pitch", version: 7, input,
  output: { type: t.PitchText, from: render.out },
  nodes: { load_hotels, score_hotels, top3, pick, render } })
```

**Откуда берётся `node_id`.** Из имени `const`: запись `nodes` — сокращённые свойства
(`ShorthandPropertyAssignment`), ключ и идентификатор один токен. Довод «id живёт в трёх местах»
верен для прокси-билдера и сюда не переносится — опровергнут прогоном §2.2.

## 1. Четырнадцать жестов: A против B

| Жест | A: операция ts-morph | A: мест | B: операция ts-morph | B: мест | Локальна |
|---|---|---|---|---|---|
| Добавить узел | `ObjectLiteral.addPropertyAssignment` | 1 | `insertStatements` + `addShorthandPropertyAssignment` | 2 | обе да, §3 |
| Удалить узел | текстовый поиск по `StringLiteral` + парс пути + `PropertyAssignment.remove()` | 1+N | `findReferencesAsNodes` + `VariableStatement.remove()` + удалить ключ | 2 | обе да |
| Переименовать | `getNameNode().replaceWithText` + `setLiteralValue` на каждой ссылке | 1+N | `VariableDeclaration.rename()` | **1** | да |
| Перепривязать слот | `PropertyAssignment.setInitializer("$x.out")` | 1 | `setInitializer("x.out")` | 1 | да |
| Отвязать слот | `PropertyAssignment.remove()` | 1 | то же | 1 | да |
| Параметр узла, `concurrency`, `maxItems` | `setInitializer` / `addPropertyAssignment` / `remove` | 1 | идентично | 1 | да |
| Ветка `switch` ±1 | `cases.addPropertyAssignment` / `.remove()` | 1 | идентично | 1 | да |
| `parallel`: состав | `ArrayLiteral.insertElement/removeElement` | 1 | идентично | 1 | да |
| Обернуть в компонент | перенос `PropertyAssignment` + переписать входящие на `"$in.*"` и исходящие | 1+6 | перенос `VariableStatement` дословно | 4 | §2.3 |
| Развернуть обратно | обратная перестановка + обратная переписка строк | 1+6 | обратный перенос | 4 | §2.3 |
| Двигать/зум, тело `code`, текст промта | кодмода нет | — | кодмода нет | — | — |

Десять жестов из пятнадцати совпадают побайтово: они правят вложенный литерал, а лексические
ссылки его не меняют. Расходятся четыре — §2 и §3.

## 2. Три не-локальных жеста — прогон

### 2.1 Удаление: language service против текстового поиска

```
B findReferencesAsNodes(top3): 3   lines 47,49,66
A path-parsed string refs:     2   lines 52,55
A naive substring hits:        3   (в т.ч. ключ записи — ложное срабатывание)
B delete top3 -> live refs 3, отказ со списком: "top3.out" / "top3.out" / "top3"
```

B даёт точный список позиций от компилятора. A — только после разбора каждой строки грамматикой
04 §3.1: наивный `includes("top3")` уже на пятиузловой фикстуре даёт ложное срабатывание, а `top3`
против `top3_extra` совпал бы по префиксу. **Регулярка в кодмоде — это и есть третья реализация
грамматики путей** из рисков `shape.md`. В B её нет.

### 2.2 Переименование `top3 → top_three`

```
B ops: 1 (VariableDeclaration.rename)
B hunks: [669,689) +1/-1 | [970,986) +1/-1 | [1013,1088) +1/-1 | [1381,1441) +1/-1
A ops: 3 (1 ключ записи + 2 строковых литерала, каждый через парс пути)
A hunks: [840,852) +1/-1 | [1226,1258) +1/-1 | [1304,1341) +1/-1
```

Четвёртый диапазон в B — строка `nodes: { … }`: `rename()` сам переписал сокращённое свойство.
Место по-прежнему одно, синхронизацию держит language service, а не кодмод.

### 2.3 Обёртка в компонент

```
B: remove x2 + insert x2, перенесённый текст — 453 байта дословно
B hunks: [668,951) +12/-16 | [952,1121) +11/-6 | [1124,1125) +1/-1
B ссылок к переписке: 0
A ссылок к переписке: исходящих 3, входящих (→ "$in.*") 3
```

Жест не-локален в обеих формах. Но в B текст переезжает дословно и ни одна ссылка не
переписывается: идентификаторы сохраняют привязку внутри тела компонента, внешние ссылки ловит
`findReferencesAsNodes`. В A каждую пересекающую границу строку надо разобрать и переписать.

## 3. Добавление узла правит два места — гарантия §2 canvas-edit держится

Кодмод объявляет **два** диапазона вместо одного; диапазоны расширены до границ строк, как
требует §6 `canvas-edit`:

```
B declared: [1255,1255]  (точка вставки после stmt render)
B declared: [1381,1441]  (PropertyAssignment "nodes")
B actual  : [1255,1255) +6/-0 | [1381,1441) +1/-1
A declared: [329,1616]   (ObjectLiteral записи nodes)
A actual  : [1613,1613) +7/-0
```

Совпадение точное. Правило §2 остаётся механическим, меняется арность: **множество объявленных
диапазонов, каждый фактический лежит внутри одного из них**. Проверка общим префиксом/суффиксом
при двух правках даёт склеенный `[1255,1437)` и ложно сигналит `NON_LOCAL_EDIT` — её надо
заменить построчным diff по хункам (`probe-dsl/lib.mjs`, LCS по строкам); это единственное
изменение в механике §2. Объявленный диапазон в A шире (вся запись `nodes`, 1287 байт), в B уже
(49 байт плюс точка вставки) — B даёт **более** жёсткую гарантию.

## 4. Порядок объявлений

`const` нельзя использовать до объявления — это ошибка компилятора, а не совет. Проба `fwd.ts`
(`final_pitch` ссылается на `fix` ниже, а `fix` берёт вход из `final_pitch`):

```
fwd.ts(3,64): error TS2448: Block-scoped variable 'fix' used before its declaration.
fwd.ts(3,64): error TS2454: Variable 'fix' is used before being assigned.
fwd.ts(3,7):  error TS7022: 'final_pitch' implicitly has type 'any' … in its own initializer
runtime: ReferenceError: Cannot access 'b' before initialization
```

| Случай | Пример из `hotel_pitch` | Что делает кодмод |
|---|---|---|
| Ациклический forward-ref | `final_pitch` → `{ node: fix }`, `fix` берёт вход из `pick` | переставить: `fix` и `review` объявляются до `final_pitch`. Данные это допускают — `fix.in.pitch = pick.out.best`, от `final_pitch` он не зависит |
| Настоящий цикл | `final_pitch` → `fix`, и `fix.in ← final_pitch.out` | **невыразимо** лексически, TS2448 + TS7022. Нужен либо thunk (`() => fix`), либо строка |

Вставка узла в середину (проба T6, `filter` между `score_hotels` и `top3`):

```
deps max stmt index: 6   first user index: 7   -> insert at 7
hunks: [668,668) +5/-0   tsc errors after insert: 0
```

Правило: позиция = `max(индекс объявления зависимости) + 1`, и она обязана быть `<=` индекса
первого использования; оба числа даёт AST. Конфликт означает цикл — отказ («узел замыкает цикл»),
файл не пишется: третий вид отказа §3 `canvas-edit`. В A проблемы нет, порядок ключей свободен.
Обход для циклов — держать `goto` у `switch` строкой (`{ node: "fix" }`): данные ссылками,
управление строкой; грамматика путей всё равно не нужна, `goto` — идентификатор, а не путь.

## 5. Побайтовая сохранность

`sha256/12` тела `code`-узла (`const rows … r.hotel`) до и после, с обязательным `prettier`:

| Жест | A: тело | B: тело |
|---|---|---|
| Переименование `top3` | `3cf750a954d3 → 3cf750a954d3` | `d82cbd56fbe3 → d82cbd56fbe3` |
| Добавление узла | `3cf750a954d3 → 3cf750a954d3` | `d82cbd56fbe3 → d82cbd56fbe3` |
| Обёртка в компонент | не выполнялась (6 правок строк) | `d82cbd56fbe3 → 3a68e7ad18f0` |

Комментарий над узлом и пустая строка-разделитель внутри тела на месте во всех прогонах; вставки
дают пустой диапазон `[n,n)` — ни один существующий байт не переписан. Расхождение одно: обёртка
переносит тело на уровень глубже и `prettier` меняет отступ; при нормализации горизонтального
пробела шум исчезает (`66363d32fdb5 → 66363d32fdb5`) — текст тела не тронут. В A обёртка сдвигает
отступ так же, так что проверку §2 на этом жесте надо вести по нормализованному тексту.

## 6. Вердикт

**Кодмод на форме со ссылками надёжнее и дешевле. Берём ссылки.**

| Критерий | A (строки) | B (ссылки) |
|---|---|---|
| Жестов с идентичным кодмодом | 10 из 15 | 10 из 15 |
| Переименование | 1+N правок, парс путей | 1 вызов, правит и запись `nodes` |
| Удаление: поиск ссылок | текст + грамматика, ложные срабатывания | `findReferencesAsNodes`, точный список |
| Обёртка в компонент | 6 переписок строк | 0 |
| Ширина диапазона / грамматика путей | вся запись `nodes` / нужна | объявление узла / не нужна |
| Добавление узла | 1 место | 2 места, оба локальны, доказано |
| Порядок объявлений, цикл `goto` | свободен, выражается | топологический; `goto` строкой |

Три жеста, ради которых канвас существует как редактор, а не просмотрщик — переименование,
удаление, обёртка, — на ссылках делает language service, а на строках самописный разбор текста,
который ошибается молча. Цена (топологический порядок и строка для `goto`) локальна и проверяема
компилятором: нарушение даёт TS2448 у автора и отказ кодмода у канваса, а не порчу файла.

Что поменять в принятых документах, если вердикт принят:

| Документ | Строка | Правка |
|---|---|---|
| `shape.md` §3 | «прокси возвращает билдер, id в трёх местах» | не покрывает лексическую ссылку; опровергнуто прогоном T2 (сокращённое свойство `nodes`) |
| `canvas-edit.md` §2 | «один объявленный диапазон» | «множество диапазонов»; префикс/суффикс → построчный diff по хункам |
| `canvas-edit.md` §1 | якорь `CallExpression` со строковым `id` | якорь `VariableDeclaration` по имени, `id` из имени |
| открыто | `$item` в `map.do` | в пробе записан стрелкой `(item) => ({…})` — замыкание по ADR-0018/0019; альтернатива — магический `item` из `@wf/dsl`. Не решено |

# Выбор последнего прогона на странице Runs

> Статус: уточнено владельцем 2026-09-18 — селектор остаётся компактным.
> Область: локальная Studio, страница одного flow.

## Цель

Переход по верхней вкладке Runs должен сразу показывать последний начатый прогон этого flow. Ссылки с явным `?run=` сохраняют точный выбор. Селектор прогонов остаётся прежним: короткий ID и статус, без повторения датасета и узлов, которые уже видны в деталях страницы.

## Подход

| Вариант | Итог |
|---|---|
| Добавить `run` к ссылке верхней вкладки из `last_run` flow | Отклонён: прямой `/runs` остаётся пустым; источник выбора зависит от места перехода. |
| Разрешать отсутствие `run` в загрузчике Runs как последний элемент списка | Выбран: одинаковое поведение вкладки, прямого URL и обновления страницы без второго перехода. |
| Загружать снимок каждого прогона при открытии списка | Отклонён: дополнительные запросы и повторение информации на странице. |

Последний прогон — первый элемент `run_list` с сортировкой по `started_at` от новых к старым. При пустом списке остаётся существующее пустое состояние. Явный `?run=<id>` всегда имеет приоритет и не заменяется последним прогоном. Выбранный ID, снимок и события загружаются одним маршрутом, как сейчас.

## Представление

Закрытый селектор и раскрытые пункты сохраняют прежнюю плотность и содержимое: ID, статус, режим и относительное время. Датасет и узлы не дублируются в селекторе. Контракт `RunSummary` и поиск по ID не меняются. Выбор пункта сохраняет явный `?run=` и закрывает список.

## Состояния и проверка

Загрузка и ошибка страницы используют существующие состояния маршрута; новые запросы при открытии списка не нужны. Некорректный или недоступный явный ID не подменяется последним прогоном и проходит через существующую ошибку снимка.

Тесты проверяют: вход на `/runs` и клик по верхней вкладке выбирают последний прогон; явный ID остаётся выбранным; flow без прогонов показывает пустое состояние; селектор не дублирует датасет и узлы даже при наличии этих полей в ответе. Проходят тесты Studio, типизация и сборка.

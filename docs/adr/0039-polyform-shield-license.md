# ADR-0039. Лицензия PolyForm Shield 1.0.0: продавать AQVEN может только владелец, строить и продавать на нём — все

> Статус: **частично изменено [ADR-0045](0045-license-distribution-restriction.md)** (2026-09-22) —
> раздел `Distribution License` ужесточён (бесплатное некоммерческое распространение самого AQVEN),
> текст `LICENSE` и идентификатор в `pyproject.toml` больше не совпадают с немодифицированным PolyForm
> Shield 1.0.0. Остальные разделы этой записи в силе.
> Дата: 2026-09-21
> Зависит от: [ADR-0038](0038-publishing-to-pypi.md)
> Закрывает открытые вопросы 1 и 2 [ADR-0038](0038-publishing-to-pypi.md)
> Источники: текст лицензии — [репозиторий PolyForm](https://github.com/polyformproject/polyform-licenses/blob/1.0.0/PolyForm-Shield-1.0.0.md), сверен по исходнику 2026-09-21; список SPDX 3.29.0 получен и проверен программно; поведение `uv_build` с `LicenseRef-` проверено сборкой колеса

## Контекст

Дистрибутивы `aqven` и `aqven-llm` 0.0.0 уже лежат на PyPI **без лицензии**
([ADR-0038](0038-publishing-to-pypi.md), открытый вопрос 1). Отсутствие лицензии означает «все права
защищены» по умолчанию: формально тот, кто поставил пакет, не получил права им пользоваться. Для публично
опубликованного пакета это противоречие, которое нужно снять.

**Решение владельца от 2026-09-21** в его формулировке: разрешить использование и доработку софта локально;
результат работы — воркфлоу, которые работают в проде и приносят деньги, — это нормально; сам AQVEN, в том
числе переделанный, продавать нельзя; право продавать сам софт остаётся у владельца.

Это не open source: любое ограничение на область применения нарушает пункты 5 и 6 Open Source Definition.
Это source-available лицензия, и писать её с нуля нельзя — самодельная лицензия юридически не проверена,
не распознаётся инструментами инвентаризации и отпугивает корпоративных пользователей сильнее, чем известная
ограничительная.

## Решение

**PolyForm Shield 1.0.0.** Копирайт — Kirill Burkhanov.

Определяющий раздел лицензии:

> **Noncompete.** Any purpose is a permitted purpose, except for providing any product that competes with the
> software or any product the licensor or any of its affiliates provides using the software.

Разложение на требования владельца:

| Что хотели | Что даёт Shield |
|---|---|
| Пользоваться и дорабатывать локально | `Copyright License` и `Changes and New Works License` — любая цель, кроме конкурирующей |
| Строить воркфлоу и продавать их, в том числе в проде | воркфлоу не является заменой AQVEN, значит это permitted purpose |
| Нельзя продавать AQVEN, в том числе переделанный | форк — продукт, конкурирующий с software, значит запрещён |
| Право продажи только у владельца | `No Other Rights`: сублицензировать и передавать лицензии нельзя, а licensor волен выдавать лицензии кому угодно |

Раздел `Competition` закрывает обход: продукты конкурируют, даже если сделаны на другом языке, для другой
платформы, через другой интерфейс — **и даже если раздаются бесплатно**. То есть бесплатный форк AQVEN тоже
запрещён, а не только платный.

В файл `LICENSE` добавлены две строки, предусмотренные самой лицензией:

```
Required Notice: Copyright Kirill Burkhanov (https://aqvenstudio.com)
Licensor Line of Business: AQVEN, a platform for building, running and evaluating AI workflows (https://aqvenstudio.com)
```

Вторая строка важна из-за раздела `Discontinued Products`: без неё, прекратив предоставлять продукт, владелец
открыл бы дорогу конкурирующим использованиям.

### Как это записано в дистрибутивах

`PolyForm-Shield-1.0.0` **отсутствует в списке SPDX** — проверено программно по списку 3.29.0, там есть только
`PolyForm-Noncommercial-1.0.0` и `PolyForm-Small-Business-1.0.0`. PEP 639 допускает пользовательские
идентификаторы вида `LicenseRef-`, поэтому в обоих `pyproject.toml`:

```toml
license = "LicenseRef-PolyForm-Shield-1.0.0"
license-files = ["LICENSE"]
authors = [{ name = "Kirill Burkhanov" }]
```

Проверено сборкой: `uv_build` принимает выражение и пишет `Metadata-Version: 2.4`,
`License-Expression: LicenseRef-PolyForm-Shield-1.0.0`, `License-File: LICENSE`, а сам файл кладёт в
`dist-info/licenses/`.

`license-files` разрешается относительно папки дистрибутива, поэтому `LICENSE` лежит тремя одинаковыми
копиями: в корне репозитория и в каждом пакете. Расхождение копий ловит шаг `cmp` в джобе `engine`.

## Альтернативы

| Вариант | Почему не он |
|---|---|
| **FSL-1.1-ALv2 / FSL-1.1-MIT** (Sentry) | по существу подходит — запрещает competing use и разрешает прод, — но каждая версия **автоматически становится Apache-2.0 или MIT через два года**. Исключительное право продавать испарилось бы по расписанию, а это прямо противоречит решению владельца |
| **Elastic-2.0** | запрещает только предоставление софта как управляемого сервиса и обход лицензионных ключей. Продать форк как продукт по ней **можно** — главное требование не выполняется |
| **PolyForm Noncommercial 1.0.0** | в SPDX есть, но запрещает любое коммерческое использование, то есть ровно то, что владелец хочет разрешить: продакшен-воркфлоу, приносящие деньги |
| **BUSL-1.1** | конвертируется в открытую лицензию через change date — та же проблема, что у FSL, плюс сложнее в понимании |
| **Commons Clause поверх MIT** | определяет «Sell» как продажу продукта, ценность которого «entirely or substantially» происходит из софта. Продажа воркфлоу, работающего на AQVEN, попадает в серую зону — то есть формулировка ставит под сомнение именно тот сценарий, который надо разрешить |
| Своя лицензия | юридически не проверена, не распознаётся SPDX и сканерами, требует юриста на каждый спор |
| Оставить без лицензии | «все права защищены»: пользователь опубликованного пакета формально не имеет права его запускать |

## Последствия

- **AQVEN перестаёт быть open source и им никогда не был** — важно не называть его так в маркетинге:
  корректная формулировка «source-available».
- Версия 0.0.0 на PyPI **останется без лицензии навсегда**: метаданные опубликованной версии не меняются,
  перезалить её нельзя. Лицензия появится начиная со следующей версии.
- Корпоративные сканеры лицензий пометят `LicenseRef-PolyForm-Shield-1.0.0` как неизвестную и потребуют
  ручного одобрения. Это цена любой не-SPDX лицензии.
- Контрибьюторы со стороны потребуют отдельного решения: без CLA права на их вклад принадлежат им, и
  исключительное право владельца на продажу размывается.

## Проверка

| Проверка | Результат |
|---|---|
| текст лицензии | взят из репозитория PolyForm, тег `1.0.0`, без правок кроме двух предусмотренных строк |
| `PolyForm-Shield-1.0.0` в SPDX 3.29.0 | отсутствует; используется `LicenseRef-` |
| сборка колеса с `LicenseRef-` | `License-Expression: LicenseRef-PolyForm-Shield-1.0.0`, `License-File: LICENSE` |
| файл лицензии в колесе | `aqven-0.0.0.dist-info/licenses/LICENSE` |
| три копии `LICENSE` | идентичны (`cmp`), проверяется в CI |
| ссылки на сайт в README пакетов | все пять существуют в `apps/site/src/content/docs/` |

## Пересмотр

Запись пересматривается, если появятся внешние контрибьюторы (понадобится CLA), если владелец решит открыть
код под обычной открытой лицензией, или если `PolyForm-Shield-1.0.0` попадёт в список SPDX — тогда
`LicenseRef-` заменяется на канонический идентификатор.

## Открытые вопросы

1. **Юридическая проверка не проводилась.** Выбор сделан по тексту лицензии и практике её применения, без
   участия юриста. Закрыть: показать `LICENSE` юристу до первого релиза с лицензией, особенно раздел
   `Noncompete` в связке со строкой `Licensor Line of Business:`.
2. **CLA для внешних контрибьюторов.** Пока вкладов со стороны нет, но первый же PR создаёт проблему.
   Закрыть: решение владельца о CLA или DCO до открытия репозитория для внешних PR.

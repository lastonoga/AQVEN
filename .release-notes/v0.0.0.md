# AQVEN 0.0.0

**Alpha, and the first published release.** No changelog existed before this one, so this body
was reconstructed from the history reachable only through the `v0.0.0` tag (54 commits,
2026-09-14 → 2026-09-21, 53 non-merge — the later repository restart left them off `main`).

Engineer AI systems, not just prompts: files as the source of truth, a compiler, a checkpointed
runtime and a local Studio.

## What shipped in the 0.0.0 wheels

Evidence for each item is the tree at `v0.0.0`, not a public commit message.

- `aqven` — 20 subpackages under `packages/aqven/src/aqven`: `engine`, `compiler`, `spec`, `loader`, `ir`, `server`, `chat` (Claude and Codex backends), `check`, `models`, `runtime`, `policies`, `ports`, `console`, `client`, `preview`, `testing`, `write`, `evals`, `templates` (206 files of project templates)
- Studio served from the same wheel (`343e31b`): `packages/aqven/src/aqven/server/static.py`
- `aqven-llm` — provider isolation: one factory with `adapters`, `catalog`, `connectors`, `routing`, `keys`, `media`
- CLI at 0.0.0: `new`, `check`, `generate`, `schema`, `tree`, `refs`, `fmt`, `plan`, `build`, `run`, `dev`, `studio`, `serve`, `mcp`, `models`, `secrets`, `prompt`, `eval`, `optimize` (`git show v0.0.0:packages/aqven/src/aqven/cli.py`)
- Provider extras: `anthropic`, `bedrock`, `cohere`, `google`, `groq`, `huggingface`, `mistral`, `xai`
- Docs site on Astro + Starlight with the first guide pages, published to GitHub Pages (`7e0f4f8`, `f3a131b`, `2faeb1d`)

Built during this release: Studio on Vite replacing the old playground and the dropped
TypeScript engine (`ea2069e`), the Python engine with the `lumen` showcase (`e6a36cb`), the
monorepo flattened to a single root (`cb235fa`), and publishing to PyPI by tag (`3d90ee8`).

## Install

```sh
uv tool install aqven==0.0.0
```

Python 3.14 is required (`>=3.14,<3.15`); `uv` fetches it. In an existing project:
`uv add "aqven==0.0.0"`.

## Breaking changes

Not applicable — first release. Expect change: `eval` and `optimize` in this CLI are gone by
0.0.3.

## Known gaps at this release

No `LICENSE` file in the tree at `v0.0.0` (added in 0.0.1), and no GitHub Release entry was ever
published for 0.0.0.

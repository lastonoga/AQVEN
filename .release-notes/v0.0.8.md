# AQVEN 0.0.8

**Alpha.** 0.0.x means the API and the project file formats can still change between minor
versions. `aqven` pins `aqven-llm==0.0.8`, so the two packages move together.

This release teaches models what named output-enum values mean and gives coding agents deterministic
warnings about workflow contracts that can silently lose data or reliability guarantees.

## Highlights

- **Enum definitions reach the model** — named output enums now deliver each value and its declared
  description at plain, Liquid and Python prompt levels, with `prompt_preview` showing the same text.
  Per-inference `enum_definitions: auto|manual` defaults to `auto`; `manual` suppresses injection and
  emits `W_ENUM_DEFINITIONS_MANUAL`, even when definitions are already written in the prompt.
- **Eight new checker warnings** — textual identifiers (`W_TEXT_IDENTIFIER_TYPE`), missing allowed
  sets (`W_ID_ALLOWED_SET_MISSING`), unchecked coverage (`W_ID_COVERAGE_UNCHECKED`), insufficient
  coverage capacity (`W_ID_COVERAGE_CAP`), unattached nested media
  (`W_NESTED_MEDIA_NOT_ATTACHED`), hidden map item failures (`W_MAP_ITEM_FAILURE_HIDDEN`), retry
  checks that cannot retry (`W_CHECK_RETRY_UNAVAILABLE`) and dataset inputs reused across dev/holdout
  (`W_DATASET_INPUT_REUSED`).
- **Shared static analysis** — cycle-safe value-path traversal and resolved inference-usage discovery
  cover direct, optional, list, record and union declarations, local flows, variants, subagents and
  LLM judges. Warnings stay non-blocking and reach MCP by default.
- **Defensive test fixtures** — offline cassettes were migrated to actual current request hashes with
  unchanged response/events. Dataset canonicalization now excludes non-finite and unsafe numeric
  inputs from reuse analysis instead of aborting the entire check.

## Install

```sh
uv tool install aqven==0.0.8
```

Python 3.14 is required; `uv` fetches it. In an existing project: `uv add "aqven==0.0.8"`.

## Breaking changes

None. Existing projects keep their file formats and runtime JSON Schemas. Named output enums gain
prompt definitions by default; set `enum_definitions: "manual"` to own the definitions in the prompt
and receive the configuration warning.

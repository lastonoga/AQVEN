# AQVEN 0.0.1

**Alpha.** Same feature set as 0.0.0 — this release is about the repository and the
published artifacts, not about new capability.

## What actually changed

- The public repository history was **restarted as a single squashed commit** (`65fe0a4`,
  "Initial commit: AQVEN 0.0.1"). The 54 commits behind 0.0.0 are not on `main` any more; they
  are reachable only through the `v0.0.0` tag.
- Internal design material was not published in the restart: `docs/adr`, `docs/research`,
  `docs/dsl`, `docs/playground`, `docs/frontend` and `docs/files-first` are gone from the tree
  (`diff v0.0.0..v0.0.1 --diff-filter=D`).
- `LICENSE` is in the repository for the first time (absent at `v0.0.0`).
- Both distributions and the `aqven → aqven-llm` pin moved to 0.0.1 (`diff v0.0.0..v0.0.1 -- '*/pyproject.toml'`).

## Install

```sh
uv tool install aqven==0.0.1
```

Python 3.14 is required; `uv` fetches it. In an existing project: `uv add "aqven==0.0.1"`.

## Breaking changes

None — the version bump carried no code changes attributable to a public commit.

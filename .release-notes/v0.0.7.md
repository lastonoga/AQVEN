# AQVEN 0.0.7

**Alpha.** 0.0.x means the API and the project file formats can still change between minor
versions. `aqven` pins `aqven-llm==0.0.7`, so the two packages move together.

Studio's flow canvas gets a real graph layout. The previous hand-rolled algorithm wrapped the
pipeline into rows and flipped every odd row right-to-left, so a flow read like a snake; every
source node sat in one far-left column no matter where its consumer lived, and edges were drawn
as bezier curves that happily cross other nodes. One wide pipeline was enough to make the canvas
unreadable.

## Highlights

- **ELK does the layout** — the `elkjs` layered algorithm gives one left-to-right direction, no
  wrapped rows and no reversed handles; network-simplex layering pulls a step next to its
  consumers instead of stranding it with the sources (`9f9cd88`)
- **ELK routes the edges too** — each edge gets its own ports on the node's sides and an
  orthogonal route that never crosses another node's body; the colored port dots, per-source
  colors, arrow heads and the moving direction dot all stay (`9f9cd88`)
- **Loops keep a clean dashed back edge** — hand-computed through the loop's reserved bottom
  channel and a widened left channel, because ELK's cycle breaking behaved nondeterministically
  for nested loops; cycles never enter the laid-out graph (`9f9cd88`)
- **Wide pipelines fit on open** — the canvas minimum zoom drops from 0.16 to 0.05, and the
  layout runs async behind a shared `useGraph` hook on the flow canvas and the experiment page
  (`9f9cd88`)

## Install

```sh
uv tool install aqven==0.0.7
```

Python 3.14 is required; `uv` fetches it. In an existing project: `uv add "aqven==0.0.7"`.

## Breaking changes

None. This release touches Studio's canvas only; project files, the engine and the MCP API are
unchanged.

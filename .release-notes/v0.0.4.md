# AQVEN 0.0.4

**Alpha.** 0.0.x means the API and the project file formats can still change between minor
versions. `aqven` pins `aqven-llm==0.0.4`, so the two packages move together.

Four days after 0.0.3: you can now create and shape experiments from Studio instead of only
reading them, and a running series tells you how fast it is going.

## Highlights

- **Create experiments in Studio** — start one and choose its cases without leaving the browser (`bd4d3ec`)
- **Series ETA** — time left and speed next to the attempt counts, with timestamps in your own time zone (`7cdc236`)
- **Chat out of the way** — the panel collapses to the left and comes back from the project bar (`5521868`)
- **Fixes** — the spec watcher subscribes before taking its baseline, so files changed during startup are no longer missed (`21dfd1b`); the `lumen` example's bundled skill copies are back in sync (`bf75632`)
- Docs and README rewritten around the current landing page (`871c826`)

## Install

```sh
uv tool install aqven==0.0.4
```

Python 3.14 is required; `uv` fetches it. In an existing project: `uv add "aqven==0.0.4"`.

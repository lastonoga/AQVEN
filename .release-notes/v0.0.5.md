# AQVEN 0.0.5

**Alpha.** 0.0.x means the API and the project file formats can still change between minor
versions. `aqven` pins `aqven-llm==0.0.5`, so the two packages move together.

Five weeks after 0.0.4: the agent side grew up. Series and runs can be read in bulk and in
compact form over MCP, the skills no longer assume one provider or one problem shape, and
held-out rows are now genuinely held out from agents. The rest is the public face: the
landing site, the comparison pages, the platform smoke CI, and this changelog.

## Highlights

- **Bulk and compact MCP reads** — series and runs in one call, per-agent overrides, cheap drops of large files (`a8ae481`)
- **Held-out rows stay hidden** — an agent exploring a series no longer sees the rows reserved for confirmation, and `aqven run` goes through a running server when one is up (`4e356a3`)
- **`provider_options` reach every provider that can take them** — google, mistral, xai and bedrock; `aqven check` warns on the ones that cannot (`8b15c71`)
- **Skills rewritten three times over** — generic across domains and modalities (`65bab6a`), provider-neutral model choice (`6ee117c`), pattern-neutral and reading series through the new tools (`de574df`)
- **Platform smoke CI** — Windows and macOS runners install CPython 3.14 explicitly, with a tested-platforms doc (`e89d328`, `e8f43a6`)
- **Landing site** — comparison organised by the user's questions (`b91a00e`), check-and-cross cells against named products (`2c14a3c`), refreshed against their docs of 19.10.2026 (`7916c1c`), centered hero with the Studio graph (`1177b61`), search and AI-search basics (`11f45bb`), roadmap page (`84229f9`)
- **Packaging you can read** — this changelog and the release notes for v0.0.0–v0.0.4 (`e3b9118`), Claude Code marketplace file and FAQ (`02e0b88`), pull request template (`fd94f69`), plugin directory validation hook (`dfa1f86`)
- Repository is English-only (`6afe902`)

## Install

```sh
uv tool install aqven==0.0.5
```

Python 3.14 is required; `uv` fetches it. In an existing project: `uv add "aqven==0.0.5"`.

## Breaking changes

None found in `v0.0.4..v0.0.5`. Two behaviours changed on purpose:

- `aqven run` now goes through a running project server instead of starting an engine of its
  own, so a run lands in the same run list Studio shows (`4e356a3`).
- Held-out dataset rows are no longer readable by agents during a series (`4e356a3`).

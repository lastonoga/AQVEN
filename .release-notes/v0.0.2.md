# AQVEN 0.0.2

**Alpha.** A stability release one day after 0.0.1: nothing new in the file formats, several
things that used to misbehave now do not.

## Highlights

- **`aqven new` wizard hardened** — it survives bad input and stops claiming to have written an `.env` it did not write (`923e3c7`)
- **Graceful shutdown fixed** — SSE streams no longer block it, and `aqven dev` prints a real startup banner (`454e819`)
- **Studio canvas reads better** — hover to trace an edge with visible coloured port dots (`a46c13c`), spread ports coloured by source with the flow direction animated (`7224a1c`), fewer edge crossings from rank ordering (`b8607ec`), and wrapped rows no longer strand their cross-row edges (`2f86693`)
- **Templates make the dataset and evals step required** rather than an afterthought (`6f8aeda`)
- **The `lumen` example works from recorded cassettes** — the missing scenario cassettes were recorded along with the model-reliability bugs behind them (`6151a22`)
- The project page is folded into Settings and dropped from the flow picker (`a579b97`); new docs page on customising a node's display in Studio (`4d79d4d`)

## Install

```sh
uv tool install aqven==0.0.2
```

Python 3.14 is required; `uv` fetches it. In an existing project: `uv add "aqven==0.0.2"`.

## Breaking changes

None.

> Packaging note: the first 0.0.2 build pinned `aqven → aqven-llm==0.0.1`; it was repinned to the
> matching 0.0.2 before this release shipped (`e1cb892`). The wheel published on PyPI declares
> `Requires-Dist: aqven-llm==0.0.2` — checked via `https://pypi.org/pypi/aqven/0.0.2/json`.

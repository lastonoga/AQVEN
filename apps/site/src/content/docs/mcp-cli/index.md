This is the agent-driven way into the same project the [Engine](/engine/) and [Studio](/studio/) pages
cover — no human clicking through a browser, just a coding agent calling tools directly: checking and
testing a project, editing a flow's structure, starting and following runs, running experiments as
series, and previewing exactly what a prompt will send. Put together, they let an agent take a task to a
flow that works reliably, round after round.

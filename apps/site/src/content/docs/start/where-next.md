## Writing workflows in code

Define flows and nodes as files, write prompts and step code directly, and run everything from the command line. Start with [Engine](/engine/).

## Working in Studio

Build, run, and debug flows visually in the browser, with the graph, the run trace, and the checks all in one place. Start with [Studio](/studio/).

## Driving it through an agent

Point a coding agent at your project over MCP and have it create, run, and fix flows for you. Start with [MCP & CLI](/mcp-cli/).

## Understanding how it works

Read [the engineering loop](/concepts/engineering-loop/) to see how AQVEN takes you from an unexpected result to a verified fix. If you're deciding whether to trust this with production load, start with [what this is built on](/concepts/what-this-is-built-on/) instead.

---
title: Dataset Batches
description: Run several source-backed cases, monitor each start, and inspect results without losing case identity.
---

Select cases on **Datasets**, verify the selected range works for every case, and start the batch. Studio records progress and a run ID or start error for each case.

![Case selection begins from the Dataset view.](/images/studio/dataset-controls.png)

Open individual runs to inspect traces. A batch is useful for reproducing a known class of behavior; use an [Evaluation](/studio/evaluations/) when you need scorer results or a gate. Keep the dataset file and its cases meaningful because each recorded result points back to their identity.

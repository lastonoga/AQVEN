---
title: Studio AI Assistance
description: Use Studio chat with selected project and flow context while keeping source changes reviewable.
---

Studio chat connects to a configured coding-agent backend and retains sessions for the project and selected flow. Give it a task, evidence such as a run or dataset case, and a verification request.

<img src="/images/studio/chat.png" alt="A new Studio chat thread with workflow orientation questions." width="360" height="240" style="height: 240px; object-fit: cover; object-position: top;" />

Ask the agent to inspect before editing, propose the smallest change, run checks, and report results. Review its tool activity and any requested approval. Studio chat is not a separate source of truth: project files, datasets, generated references, and run traces remain the evidence.

[Coding Agents](/engineering/ai-coding-agents/) and [Project MCP Server](/engineering/project-mcp-server/) describe the related engineering workflow.

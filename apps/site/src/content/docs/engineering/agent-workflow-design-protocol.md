---
title: Agent Workflow Design Protocol
description: Give coding agents a repeatable method for turning a product requirement into a typed workflow proposal.
---

Before writing source, an agent should discover outcome, user, inputs, expected output, evidence sources, deterministic work, model judgment, external actions, human decisions, provider constraints, limits, and examples that define success.

Then the agent proposes types, nodes, field paths, failure behavior, review boundaries, datasets, and evaluations. Each step should state why it is code, a model, a tool, a human, or a control node. Use [Design a Workflow](/engineering/designing-workflows/) for the detailed engineering questions.

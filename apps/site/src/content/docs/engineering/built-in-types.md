---
title: Built-in Types
description: Choose the built-in primitive, media, and dynamic types used in AQVEN contracts.
---

AQVEN provides primitives for text, numeric values, booleans, dates and times, JSON-like values, and media. Use a declared project type when the primitive needs a reusable name or a custom constraint.

Media types represent images, audio, video, and documents as stored values rather than prompt strings. A `Dynamic` value remains opaque until a [Narrow Node](/engineering/calls-and-narrowing/#narrow-a-dynamic-value) validates it against a declared type.

The generated [Accepted Values](/engineering/reference/accepted-values/) and [Media Reference](/engineering/reference/media/) are the current authority for built-in names and shapes.

---
title: Process Images, Audio, Video, or Documents
description: Carry media as typed project data and select a model route that actually supports the required modality.
---

Declare the media field in the flow input type, bind the value into the inference, and choose a provider capability compatible with it. Test a valid media value, missing optional media, unsupported media, and the maximum practical file size. Do not stringify a blob into prompt text.

Read [Types and Structured Output](/engineering/types/#media-fields-images-audio-video-documents) and [Model Capabilities](/engineering/model-capabilities/).

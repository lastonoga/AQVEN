---
title: Build an Iterative Draft-and-Review Loop
description: Improve a typed artifact with a bounded loop, a measured stopping condition, and result selection.
---

Use a loop only when a reviewer can provide information that improves the next draft. Declare initialization bindings, a small maximum iteration count, a stop policy, and a select policy. Compare the selected result against the initial draft on cases where the reviewer helps and where it makes things worse.

Read [Loops](/engineering/loops/) and [Model Reliability](/engineering/model-reliability/).

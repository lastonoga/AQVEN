---
title: Reproduce a Production Failure with a Dataset
description: Preserve the evidence of a failure as a named case before modifying a workflow.
---

Create a dataset case with the original inputs, declared context, expected property, and boundary fixtures only when a partial run needs them. Name it for the failure condition. Run it before and after the change, then retain it as a regression case.

Read [Datasets](/engineering/datasets/) and [Improve a Workflow](/engineering/improve-a-workflow/).

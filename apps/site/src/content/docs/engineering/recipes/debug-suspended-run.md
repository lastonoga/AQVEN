---
title: Use Studio to Debug a Suspended Run
description: Inspect a durable wait, its evidence, deadline, and expected form before safely resuming the run.
---

Open the run and locate its wait, then open **Review**. Inspect the run/node address, evidence, form schema or proposed tool call, assigned reviewer, and deadline. Submit one typed answer, then return to the run trace to inspect the resumed path.

Read [Human Review](/studio/human-review/) and [Run Lifecycle](/engineering/run-lifecycle/).

---
title: Require Approval Before an External Action
description: Gate a model-requested write or external tool action before the side effect happens.
---

Declare the tool effect and idempotency boundary, give the agent only that required tool, and list it in agent approval. Choose a real assignee, deadline, and timeout policy. Test allow, deny, timeout, and repeated-request behavior.

Read [Tool Approval and Human Review](/engineering/tool-approval/) and [External Effects](/engineering/external-effects/).

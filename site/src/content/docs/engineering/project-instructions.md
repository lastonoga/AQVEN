---
title: Project Instructions
description: Write an AGENTS.md that tells coding agents how this specific AQVEN project must be changed and verified.
---

Keep project facts close to the source tree in `AGENTS.md`: project root, generated-file rules, provider and credential policy, approved external effects, dataset ownership, required checks, and local Studio launch command.

An instruction file should tell an agent which facts are stable and which decisions need an owner. It should require the agent to inspect source before editing, use generated references for fields, update datasets for behavior changes, and report verification evidence.

[AI Coding Agents](/engineering/ai-coding-agents/) provides a reusable starting contract.

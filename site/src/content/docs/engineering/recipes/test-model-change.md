---
title: Test a Model Change with Cassettes
description: Separate deterministic regression evidence from a live model comparison.
---

Use cassettes or fakes for deterministic test coverage of existing behavior. Run a live evaluation on the same representative dataset when changing model, provider, output mode, or prompt. Record cost, latency, validation failures, and task quality rather than comparing prose by eye.

Read [Automated Tests](/engineering/automated-tests/) and [Testing and Evaluation](/engineering/testing-and-evaluation/).

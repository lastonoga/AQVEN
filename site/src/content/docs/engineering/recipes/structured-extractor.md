---
title: Create a Structured Extractor
description: Extract declared fields from text while preserving missing or uncertain evidence.
---

Define a record output with one field per fact, nullable fields for unsupported facts, and optional evidence or uncertainty fields. Bind source text into an inference, use an agent with structured output, then validate the result through the record type. Add cases for clear evidence, missing evidence, contradictory evidence, and malformed text.

Read [Schema Design](/engineering/schema-design/), [Model Nodes](/engineering/model-nodes/), and [Structured Output](/engineering/structured-output/).

---
title: Answer with Retrieved Context
description: Retrieve declared evidence through a tool, then give the model only the results needed to answer.
---

Define a read tool for retrieval and a model inference whose input includes the query and retrieved records. Ask the model to state uncertainty when the records do not support an answer. Test empty results, irrelevant results, conflicting results, and a correct supported answer.

Read [Tool Nodes](/engineering/tool-nodes/) and [Prompt Design](/engineering/prompt-design/).

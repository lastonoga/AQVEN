---
title: Call an MCP Tool from a Model Agent
description: Use a remote MCP server as a model-facing tool source with an explicit server and schema boundary.
---

Declare the MCP server with a streamable HTTP URL and secret-backed headers. Either list the server directly on the agent or expose one remote tool as a project Tool. Keep the available action set small and test a read operation before a write.

Read [MCP Connections](/engineering/mcp-connections/).

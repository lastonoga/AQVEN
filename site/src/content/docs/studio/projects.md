The **Project** page shows the opened project root, package, engine version, index state, diagnostics, and known flows. Choose a flow to work in its Canvas, Nodes, Runs, Datasets, or Evals views.

![The workflow list on Studio's Project page.](/images/studio/project-flows.png)

The flow list is the fastest way to confirm that Studio loaded the project you expected. If a flow is missing, check the project root and the index diagnostics on this page, then run `{{CLI_COMMAND}} check` in the project directory.

Studio has a chat panel beside flow views when a supported coding-agent backend is configured. [AI assistance](/studio/ai-assistance/) explains how to use it. For a full source map, see [Project layout](/engineering/project-layout/).

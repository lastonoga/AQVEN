---
title: Start a Run
description: Start a full flow in Studio with manual input and declared run context.
---

Open a flow, choose **Runs**, then choose **Start a run**. Keep the range set to the entire flow, complete the form derived from the flow input type, and fill only the context keys the flow declares.

![The Runs view provides the entry point for a manual run.](/images/studio/runs.png)

Review the selected input and live mode before starting. A live run can call providers and external tools. Use a dataset case when the input should be repeatable. After start, Studio opens the run and its trace. [Read a Run](/studio/read-a-run/) explains what the recorded evidence means.

---
title: Manage a Run
description: Resume a wait, fork a run from an execution address, cancel work, and preserve investigation evidence.
---

When a run waits for a person or protected tool action, open [Review](/studio/human-review/) and answer the current wait. Studio sends the run ID, execution address, and attempt, so an expired or stale wait cannot be resumed accidentally.

![Use the run header to confirm the execution you are about to investigate.](/images/studio/runs.png)

Fork a run to rerun one execution and later work while retaining earlier recorded work. Cancel a run when it should no longer continue; its trace remains available. A fork is a new run with lineage, and it may create a new human wait. Use the recorded run instead of memory when reporting a failure.
